<div class="frc-section-title">
  <i class="ti ti-target frc-ico"></i>
  מה מייחד את ראש הצוות?
</div>

בעוד הקפטן רואה את התמונה הכללית של הקבוצה, ראש הצוות **מתמקד בצוות שלו** — הצוות הוא האחריות המרכזית שלו. הוא צריך להכיר לעומק את התחום, ולהוביל את חברי הצוות לתוצאה.

<div class="frc-grid-2">
  <div class="frc-card">
    <strong>חלוקת עבודה</strong>
    <p style="margin: 0.4rem 0 0;">מחלק את המשימות בין חברי הצוות ודואג שכולם עובדים לפי הזמנים.</p>
  </div>
  <div class="frc-card">
    <strong>סמכות החלטה</strong>
    <p style="margin: 0.4rem 0 0;">כראש הצוות, יש לו הסמכות להחליט מה עושים וכיצד הצוות מתקדם.</p>
  </div>
  <div class="frc-card">
    <strong>הכשרת הצוות</strong>
    <p style="margin: 0.4rem 0 0;">דואג שחברי הצוות מקבלים את ההכשרות הנדרשות וכמה שיותר מוכנים לעבודה.</p>
  </div>
  <div class="frc-card">
    <strong>ניהול מלאי</strong>
    <p style="margin: 0.4rem 0 0;">מוודא שיש לצוות מספיק חומרים וציוד כדי לעבוד ברציפות.</p>
  </div>
</div>

  </div>

  </div>
