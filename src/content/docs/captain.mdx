<div class="frc-section-title">
  <i class="ti ti-eye frc-ico"></i>
  מה מייחד את הקפטן?
</div>

הקפטן רואה את **התמונה הכללית** של הקבוצה, וזה הכוח המרכזי שלו. בעוד ראש צוות מתמקד בצוות הספציפי שלו, הקפטן אחראי על כלל הקבוצה.

<div class="frc-grid-2">
  <div class="frc-card">
    <strong>ניהול הקבוצה</strong>
    <p style="margin: 0.4rem 0 0;">ניהול כוח אדם וקבלת החלטות מתוך ראייה כוללת של מה שקורה בקבוצה.</p>
  </div>
  <div class="frc-card">
    <strong>ייצוג הקבוצה</strong>
    <p style="margin: 0.4rem 0 0;">מייצג את הקבוצה בתחרויות, כנסים, מול בית הספר ומול ההורים.</p>
  </div>
  <div class="frc-card">
    <strong>דמות מקשרת</strong>
    <p style="margin: 0.4rem 0 0;">מגשר בין ראשי הצוותים, בין חברי הקבוצה למובילים, ובין המנטורים לקבוצה.</p>
  </div>
  <div class="frc-card">
    <strong>ניהול לוחות זמנים</strong>
    <p style="margin: 0.4rem 0 0;">מכין לו״ז, בודק שהכל עובד לפי הזמנים, ומקבל החלטות כשצריך לתקן.</p>
  </div>
</div>

<div class="frc-section-title">
  <i class="ti ti-adjustments frc-ico"></i>
  איך מנהלים? מציאת האיזון
</div>

יש שתי גישות ניהול, והמפתח הוא למצוא את האיזון ביניהן לפי הסיטואציה:

<div class="frc-grid-2">
  <div class="frc-card">
    <strong>קבוצה מיודעת</strong>
    <p style="margin: 0.4rem 0 0;">כל הקבוצה מרגישה שייכות, משתפת פעולה, וכולם יודעים מה קורה. מתאים למצבים שבהם כל דעה חשובה.</p>
  </div>
  <div class="frc-card">
    <strong>קבוצה ממוקדת</strong>
    <p style="margin: 0.4rem 0 0;">הדגש הוא על סיום המשימה במהירות. אדם אחד מנהל את התהליך וכולם פועלים לפי ההוראות שלו.</p>
  </div>
</div>

<div class="frc-section-title">
  <i class="ti ti-calendar frc-ico"></i>
  מטרות אוף סיזן מול מטרות עונה
</div>

<div class="frc-grid-2">
  <div class="frc-card">
    <strong> אוף סיזן — ללמוד ולהשתפר</strong>
    <p style="margin: 0.4rem 0 0;">יש הרבה זמן, והמטרה היא ללמוד לנהל, ללמד את החדשים, להכיר מערכות וכלים חדשים, ולתרגל עבודה בזמנים כהכנה לעונה.</p>
     <p style="margin: 0.4rem 0 0;">(נותה לקבוצה מיודעת)</p>
  </div>
  <div class="frc-card">
    <strong>עונה — ללמוד ולהצליח</strong>
    <p style="margin: 0.4rem 0 0;">אין הרבה זמן, והמטרה היא לבנות את הרובוט הטוב ביותר. עובדים לפי לו״ז, פותרים בעיות מהר, ומקיימים שיחות מוביל שבועיות. </p>
    <p style="margin: 0.4rem 0 0;">(נותה לקבוצה ממוקדת)</p>
    
  </div>
</div>

<div class="frc-card">
  <strong>טיפ: שלושה לוחות זמנים</strong>
  <p style="margin: 0.4rem 0 0;">כדאי לבנות שלושה לו״זים: ריאלי (מה שצפוי לקרות), פסימי (תרחיש שלילי), ואופטימי (תרחיש חיובי).</p>
</div>

<div class="frc-section-title">
  <i class="ti ti-message frc-ico"></i>
  תקשורת — הבסיס לכל
</div>

תקשורת טובה שומרת על כל הקבוצה מעודכנת, וזה חשוב בכל תקופה:

<div class="frc-grid-2">
  <div class="frc-card">
    <strong>עדכון יומי</strong>
    <p style="margin: 0.4rem 0 0;">עדכון ערב על ההתקדמות בכל צוות — מה נעשה היום ומה עוד נעשה.</p>
  </div>
  <div class="frc-card">
    <strong>סיכומי יום</strong>
    <p style="margin: 0.4rem 0 0;">שליחת סיכום למי שלא הגיע, כדי שכולם יישארו מעודכנים.</p>
  </div>
  <div class="frc-card">
    <strong>ישיבות קבוצה</strong>
    <p style="margin: 0.4rem 0 0;">לפחות פעם בשבוע, מפגש של כל הקבוצה.</p>
  </div>
  <div class="frc-card">
    <strong>למה זה קריטי</strong>
    <p style="margin: 0.4rem 0 0;">כשחברי קבוצה לא יודעים מה קורה, יורד להם הרצון להגיע ולהשקיע. תקשורת שומרת על השייכות.</p>
  </div>
</div>

<div class="frc-section-title">
  <i class="ti ti-trending-up frc-ico"></i>
  איך משתפרים?
</div>

<div class="frc-grid-2">
  <div class="frc-card">
    <strong>מוביל פתוח</strong>
    <p style="margin: 0.4rem 0 0;">בשיחת מוביל משאירים כיסא פנוי. כל חבר קבוצה יכול לבוא, להתיישב, ולומר את דעתו בנושא.</p>
  </div>
  <div class="frc-card">
    <strong>ניתוח SWOT</strong>
    <p style="margin: 0.4rem 0 0;">בדיקה שיטתית של חוזקות, חולשות, הזדמנויות ואיומים — גם לקבוצה וגם לצוותי תחרות.</p>
  </div>
</div>

<div class="frc-card">
  <strong>מה זה SWOT?</strong>
  <p style="margin: 0.4rem 0 0;"><strong>חוזקות</strong> — יתרונות קיימים. <strong>חולשות</strong> — חסרונות לתיקון מהיר. <strong>הזדמנויות</strong> — משהו שעוד לא קרה אך יכול להפוך ליתרון. <strong>איומים</strong> — סכנה שאם לא נטפל בה תהפוך לחולשה.</p>
</div>
